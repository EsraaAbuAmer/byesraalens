# Esraa's Lens — Photography Portfolio

A cinematic photography portfolio built with Next.js — featuring dynamic galleries, editorial layouts, and interactive before/after editing.

---

## ✨ Overview

This project is a personal photography portfolio designed to showcase visual work in a modern, immersive way.  

It focuses on storytelling through layout, motion, and minimal design.

---

## 🎯 Features

- 📸 Dynamic gallery layouts (split, grid, editorial styles)

- 🎞️ Horizontal scroll carousel for highlights

- 🎚️ Before / After image comparison slider

- 🌊 Smooth scrolling and parallax effects

- 📱 Fully responsive (custom mobile + desktop layouts)

- 🎨 Clean, cinematic UI with Tailwind CSS

---

## 🛠️ Tech Stack

- **Next.js**

- **React**

- **Tailwind CSS**

- **Framer Motion**
